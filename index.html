Method

1. Financing amount = Sales price - Deposit.

2. Total term charges (Sixth Schedule): C = (N x P x R) / (100 x T x (1 - (1 + R / (100 x T))^-N)) - P, where P = financing amount, R = EIR % p.a., T = 12, N = tenure in months.

3. Monthly instalment = (P + C) / N, rounded up to the nearest ringgit (no decimals).

4. Each month: term charges = opening balance x EIR / 12; principal = instalment - term charges; closing balance = opening balance - principal.

5. Final instalment = remaining opening balance + (total term charges - sum of term charges for months 1 to N-1), rounded up to the nearest ringgit. The rounding (less than RM1) is added to the final term charges.
